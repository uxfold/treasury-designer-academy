# Treasury Designer Academy

Stage-based learning game for product designers: evaluating AI outputs, designing missing agentic UI components, agent orchestration logic, and deep treasury business fundamentals (FX exposures, ALM, duration gap, liquidity/maturity ladders, hedge ladders).

Built as a single-file HTML/JS progressive academy with localStorage progress, quizzes, component demos, real formulas, and curated video references from 2025–2026 research.

## How to use

1. Open `index.html` directly in a browser, or
2. Enable GitHub Pages on the `main` branch (Settings → Pages → Deploy from branch) and visit the published URL.

Progress is saved in localStorage. Complete stages sequentially to unlock the next.

## Stages

1. **Evaluating AI Outputs** — Design Theater, 10-point checklist, data realism, content trust.
2. **Missing Agentic Components** — The 6 primitives design systems still lack, retry without spinner, tiered permissions, confidence footers.
3. **Agent Orchestration Logic** — Failure decision tree, idempotency, checkpoints, backoff with jitter, handoff packets.
4. **Treasury Business Fundamentals** — Transactional/translational/economic FX, duration gap formula + example, maturity ladder table, staggered hedge tenors, why this domain knowledge is the differentiator.

Research sources include Setproduct agent UI patterns (Sep 2026), Design Theater arXiv paper, Wiro/SEM Nexus retry rules, RiskHub ALM explanations, Mesirow hedge ladder analysis, and Corporate Finance Explained videos.

This is the combination almost no one is teaching: taste + evaluation + agentic patterns + real treasury domain knowledge.
